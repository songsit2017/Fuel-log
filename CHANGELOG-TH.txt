FuelLog Pro v5.0.3 — สรุปการแก้ไขจากไฟล์ต้นฉบับ (FuelLog-Pro-v5.0.1-UI-Hotfix)
================================================================

ไฟล์ทั้งหมดในโฟลเดอร์นี้พร้อมใช้แล้ว อัปโหลดทับไฟล์เดิมทั้งหมดบน GitHub ได้เลย
(ชื่อไฟล์เหมือนเดิมทุกไฟล์ ทับได้ตรงๆ ไม่ต้องแยกว่าไฟล์ไหนเปลี่ยนบ้าง)

⚠️ ข้อยกเว้นเดียว: ไฟล์ firestore.rules ต้องเอาไปวางในหน้าเว็บ Firebase
Console เองด้วยครับ (Firestore Database > Rules > Publish) เพราะไม่ได้
ทำงานจากการอัปโหลดขึ้น GitHub เหมือนไฟล์อื่น ๆ

--------------------------------------------------------------
รายการแก้ไข/เพิ่มเติมทั้งหมด (เรียงตามลำดับที่ทำ)
--------------------------------------------------------------

1. แก้บั๊ก syntax error ที่ทำให้ทั้งแอปกดอะไรไม่ได้เลยหลังจากล็อกอิน
   (วงเล็บขาดในฟังก์ชัน dueItems)

2. เขียนตัวนำเข้าไฟล์ Fuelio (.fuelio / .csv / .zip) ใหม่ทั้งหมด ให้อ่าน
   โครงสร้างไฟล์จริงถูกต้อง รองรับหลายคันในไฟล์เดียว ดึงประวัติค่าใช้จ่าย
   อื่นๆ (Costs) และรูปภาพจาก pictures.data มาแนบให้อัตโนมัติ (ทดสอบกับ
   ไฟล์ backup จริงแล้ว)

3. เพิ่มการ์ด "ปั๊มน้ำมันใกล้เคียง" และ "ราคาน้ำมันวันนี้" กลับเข้าหน้าแรก
   พร้อมช่องกรอกเวลาในฟอร์มเติมน้ำมัน (ของเดิมมีแต่วันที่)

4. แก้บั๊กร้ายแรง: localStorage ไม่เคยทำงานจริงมาตั้งแต่ต้น (พิมพ์ผิดเป็น
   window.store แทน window.localStorage) ทำให้ข้อมูลที่ไม่ได้ sync ขึ้น
   Firebase เสี่ยงหายทุกครั้งที่ปิด/รีเฟรชแอปโดยไม่มีใครรู้ตัว

5. เพิ่มฟีเจอร์ใหญ่ 5 อย่าง: บันทึกทริปด้วย GPS, เตือนบำรุงรักษาแบบวนซ้ำ
   อัตโนมัติ, รายงานกราฟโดนัท+เทียบเดือน, ตั้งค่าหน่วย กม./ไมล์ และ
   ลิตร/แกลลอน, ค้นหาทุกอย่างในที่เดียว

6. แก้บั๊ก: ปุ่ม "×" และ "ยกเลิก" ในฟอร์มไม่ได้ระบุ type="button" ทำให้
   กลายเป็นปุ่มบันทึกฟอร์มโดยไม่ตั้งใจ (บันทึกเองทั้งที่ยังไม่ได้กดบันทึก)
   พร้อมเพิ่มการตรวจสอบข้อมูลก่อนบันทึกด้วย

7. แก้บั๊ก: ปุ่ม "รีเฟรช" ปั๊มใกล้ฉันในแท็บเติมน้ำมันผูกกับฟังก์ชันผิด ทำให้
   กดแล้วไม่ทำอะไรเลย และทำให้ปั๊มใกล้เคียงค้นหาอัตโนมัติเมื่อเข้าแท็บ
   หน้าแรก/เติมน้ำมัน หรือเปิดแอป ไม่ต้องกดปุ่มเองแล้ว

8. เพิ่มทางสำรอง (CORS proxy) ให้ระบบราคาน้ำมันวันนี้ กรณี API ต้นทาง
   บล็อกการเรียกตรงจากเบราว์เซอร์ และแก้ไม่ให้ Service Worker เก็บราคา
   เก่าค้างไว้

9. แก้บั๊ก: กด "สร้างรหัสเชิญ" ครั้งแรกสุด (ก่อนเคยกดซิงก์) ขึ้น error
   "Missing or insufficient permissions" เพราะกฎ Firestore พังตอนเช็ค
   รถที่ยังไม่เคยถูกสร้างในคลาวด์ — แก้ทั้งฝั่งโค้ดแอปและฝั่งกฎ Firestore

10. เปลี่ยนชื่อปุ่ม "ซิงก์รถนี้" เป็น "ซิงก์ข้อมูลยานพาหนะ"
