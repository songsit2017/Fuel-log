FuelLog 5.0.8 Oil + OCR Patch

ทับไฟล์เดิม:
- app.js
- index.html
- sw.js

ต้องมี oil-prices.json อยู่ที่รากโปรเจกต์เหมือนเดิม

เพิ่ม:
- ราคาน้ำมันอ่าน oil-prices.json ก่อน แล้วค่อย fallback ไป API
- cache ราคาล่าสุดไว้ดูเมื่อ API ล่ม
- ปุ่มสแกนบิลในฟอร์มเติมน้ำมัน
- ปุ่มสแกนบิลในฟอร์มค่าใช้จ่าย
- OCR พยายามกรอกวันที่ ยอดรวม ลิตร ราคา/ลิตร และชื่อร้าน

หมายเหตุ:
OCR ใช้ Tesseract.js และต้องใช้อินเทอร์เน็ตครั้งแรกเพื่อโหลดภาษาไทย/อังกฤษ
ควรตรวจค่าที่ OCR กรอกก่อนบันทึกทุกครั้ง
ไม่ต้องแก้ Firebase Rules
