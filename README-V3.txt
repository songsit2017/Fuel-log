FuelLog Pro v3
==============
เปิดใช้งานผ่าน HTTPS หรือ localhost เพื่อให้ PWA และ Service Worker ทำงานครบถ้วน

ฟีเจอร์หลัก
- Dashboard และ Health Score
- หลายคัน แยกข้อมูลอิสระ
- บันทึกน้ำมันและค่าใช้จ่าย/งานซ่อม
- วิเคราะห์ กม./ลิตร บาท/กม. รายเดือน หมวดค่าใช้จ่าย และปั๊ม
- รอบบำรุงรักษาตามเลขไมล์หรือวันที่
- ค้นหา ธีมมืด/สว่าง และสีหลัก
- IndexedDB พร้อมย้ายข้อมูล localStorage เดิมอัตโนมัติ
- จุดคืนค่า Export JSON และ CSV
- legacy.html เก็บเวอร์ชันเดิมที่มี Google Drive, สแกนบิล และ Fuelio import

สำคัญ: ห้ามเปิดจาก file:// โดยตรง เพราะเบราว์เซอร์จะจำกัด IndexedDB/PWA บางส่วน
