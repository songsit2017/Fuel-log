FuelLog Pro v4.1 — Family Photo Sharing

เพิ่มจาก v4.0:
- แชร์รูปใบเสร็จและรูปเรือนไมล์ผ่าน Firebase Storage
- ดาวน์โหลดรูปของสมาชิกมาเก็บใน IndexedDB อัตโนมัติ
- รูปสัมพันธ์กับรายการเติมน้ำมันและรถแต่ละคัน
- Owner/Editor อัปโหลด แก้ไข และลบรูปได้
- Viewer และสมาชิกเปิดดูรูปได้ตามสิทธิ์ของรถ
- จำกัดรูปไม่เกิน 5 MB ที่ Storage Rules (แอปย่อรูปก่อนอัปโหลดอยู่แล้ว)
- ซิงก์รูปที่ค้างเมื่อกลับมาออนไลน์

ต้องเปิด Firebase Storage และ Publish storage.rules ตาม FIREBASE-SETUP-TH.md
