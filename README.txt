สมุดเติมน้ำมัน — PWA (ติดตั้งบน Android ได้)
================================================

วิธีใช้งาน 2 แบบ:

แบบที่ 1: ติดตั้งเป็นแอปผ่าน Chrome (เร็วที่สุด ไม่ต้องมี .apk)
-----------------------------------------------------------------
1. อัปโหลดโฟลเดอร์นี้ทั้งหมดขึ้นเว็บโฮสติ้งที่รองรับ static site เช่น Netlify
   (ลากทั้งโฟลเดอร์วางที่ app.netlify.com/drop ได้เลย ฟรี)
2. เปิดลิงก์ที่ได้ด้วย Chrome บนมือถือ Android
3. แตะเมนู (จุดสามจุดมุมขวาบน) > "เพิ่มลงหน้าจอโฮม" / "Install app"
4. จะได้ไอคอนแอปบนหน้าจอโฮม เปิดแล้วเต็มจอเหมือนแอปจริง ใช้งาน offline ได้

แบบที่ 2: แปลงเป็นไฟล์ .apk ติดตั้งจริง
-----------------------------------------------------------------
1. ทำตามแบบที่ 1 ให้มีลิงก์เว็บที่ deploy แล้วก่อน
2. เข้า https://www.pwabuilder.com
3. ใส่ URL ของเว็บที่ deploy ไว้ กด "Start"
4. เลือกแท็บ Android > กด "Generate Package"
5. จะได้ไฟล์ .apk (หรือ .aab สำหรับ Play Store) ดาวน์โหลดมาติดตั้งบนเครื่อง Android ได้เลย
   (ต้องเปิด "อนุญาตติดตั้งจากแหล่งที่ไม่รู้จัก" ในตั้งค่า Android ก่อน)

การสแกนบิล
-----------------------------------------------------------------
ต้องใส่ Anthropic API key ของตัวเอง (สมัครที่ console.anthropic.com)
กดไอคอนเฟือง (⚙️) มุมขวาบนของแอป แล้ววาง key ลงไป — เก็บไว้ในเครื่องนี้เท่านั้น

สำรองข้อมูลขึ้น Google Drive อัตโนมัติ (ทำครั้งเดียว)
-----------------------------------------------------------------
ข้อมูลปกติเก็บในเครื่อง (localStorage) เท่านั้น ถ้าอยากให้สำรองขึ้น Google
Drive อัตโนมัติทุกครั้งที่บันทึกรายการ ต้องสร้าง Google OAuth Client ID
ของตัวเอง (ฟรี ทำครั้งเดียว ใช้ได้ตลอด):

1. เข้า https://console.cloud.google.com/ (ล็อกอินด้วย Google account)
2. สร้างโปรเจกต์ใหม่ (มุมซ้ายบน > New Project) ตั้งชื่ออะไรก็ได้ เช่น "fuel-log"
3. ไปที่ "APIs & Services" > "Library" ค้นหา "Google Drive API" แล้วกด Enable
4. ไปที่ "APIs & Services" > "OAuth consent screen"
   - User Type เลือก "External" > Create
   - กรอกชื่อแอป, อีเมลตัวเอง > Save and Continue ไปเรื่อยๆ จนเสร็จ
   - ในหน้า "Test users" กด Add users ใส่อีเมล Gmail ของตัวเอง (สำคัญ! ไม่งั้น
     ล็อกอินไม่ได้เพราะแอปยังไม่ผ่านการ verify จาก Google)
5. ไปที่ "APIs & Services" > "Credentials" > "Create Credentials" >
   "OAuth client ID"
   - Application type เลือก "Web application"
   - ในช่อง "Authorized JavaScript origins" ใส่ URL ของเว็บที่ deploy ไว้
     (เช่น https://ชื่อแอป.netlify.app) — ต้องตรงกับ URL จริงเป๊ะๆ
   - กด Create จะได้ "Client ID" (รูปแบบ xxxxx.apps.googleusercontent.com)
6. เอา Client ID นี้มาวางในแอป: กดไอคอนเฟือง (⚙️) > ช่อง "Google OAuth
   Client ID" > บันทึก > กด "เชื่อมต่อ Google Drive" แล้วล็อกอินด้วย Gmail
   ที่เพิ่มเป็น test user ไว้

รวมรูปภาพในการสำรองอัตโนมัติ
-----------------------------------------------------------------
ในหน้าตั้งค่า (⚙️) มีติ๊ก "รวมรูปภาพในการสำรองอัตโนมัติ" — ถ้าเปิดไว้
ทุกครั้งที่บันทึกรายการ รูปบิล/รูปเรือนไมล์ทั้งหมดจะถูกอัปโหลดขึ้น Drive
ไปพร้อมกับข้อมูลในไฟล์ fuel-log-backup.json เดียวกันเลย (ใช้ resumable
upload อัตโนมัติถ้าไฟล์ใหญ่เกิน 4MB) ไม่ต้องกดส่งออกเองอีก
ปิดไว้เป็นค่าเริ่มต้นเพราะถ้ามีรูปเยอะจะทำให้การบันทึกแต่ละครั้งช้าลง
(ต้องอัปโหลดรูปทั้งหมดใหม่ทุกครั้ง ไม่ใช่แค่รูปที่เพิ่ม) แนะนำเปิดถ้าจำนวน
รายการ/รูปยังไม่เยอะมาก หรือถ้าไม่ได้เติมน้ำมันบ่อย

บันทึก Local ทันที + ซิงค์ขึ้น Drive เบื้องหลัง (เหมือน Fuelio)
-----------------------------------------------------------------
กด "บันทึก" แล้วข้อมูลจะถูกเซฟลงเครื่องและปิดฟอร์มทันที ไม่ต้องรอเน็ต
การอัปโหลดขึ้น Google Drive (ถ้าเชื่อมต่อไว้) จะทำงานเงียบๆ อยู่เบื้องหลัง
โดยไม่บล็อกการใช้งาน มีแถบเล็กๆ ใต้ชื่อแอปแสดงสถานะ:
  🔄 กำลังซิงค์ขึ้น Drive...   = กำลังอัปโหลดอยู่เบื้องหลัง
  ☁️ ซิงค์แล้ว เมื่อ HH:MM      = อัปโหลดล่าสุดสำเร็จเมื่อไหร่
  🔌 ยังไม่ได้เชื่อมต่อ Drive     = ยังไม่ได้ล็อกอินในเซสชันนี้

นอกจากนี้แอปจะพยายามเชื่อมต่อ Google Drive ให้อัตโนมัติแบบเงียบๆ ทุกครั้ง
ที่เปิดแอป (ถ้าเคยเชื่อมต่อสำเร็จมาก่อนอย่างน้อย 1 ครั้ง) โดยไม่ขึ้น popup
รบกวน — ถ้าเซสชัน Google หมดอายุหรือเบราว์เซอร์บล็อก third-party cookie
การเชื่อมต่ออัตโนมัตินี้อาจไม่สำเร็จ ก็แค่กด "เชื่อมต่อ Google Drive" ในหน้า
ตั้งค่าอีกครั้งเหมือนเดิม

หลังเชื่อมต่อแล้ว ทุกครั้งที่เพิ่ม/แก้ไขรายการ แอปจะอัปโหลดไฟล์
"fuel-log-backup.json" ขึ้น Drive ให้อัตโนมัติ (เห็นได้ใน Drive ปกติของพี่)
หมายเหตุ: การเชื่อมต่อจะอยู่ได้จนกว่าจะปิดแอป/รีเฟรชหน้า (ประมาณ 1 ชม.)
เปิดแอปใหม่ต้องกด "เชื่อมต่อ Google Drive" อีกครั้ง — ถ้าอยากกู้คืนข้อมูล
กดปุ่ม "กู้คืนจาก Drive" ในหน้าตั้งค่าได้ทุกเมื่อ

ถ้าไม่อยากตั้งค่า OAuth เลย ก็ยังใช้ปุ่ม "ส่งออก" เพื่อโหลดไฟล์ JSON
มาเก็บใน Google Drive เองแบบมือได้เหมือนเดิม

หลายคัน (Multi-vehicle)
-----------------------------------------------------------------
เพิ่มรถได้ไม่จำกัดจำนวน (จำกัดแค่พื้นที่เก็บข้อมูลของเบราว์เซอร์ ~5-10MB
ซึ่งเพียงพอสำหรับหลายพันรายการ) สลับรถได้จากแถบชิปด้านบนของแอป
กดไอคอน "⚙️ จัดการรถ" เพื่อเพิ่ม/เปลี่ยนชื่อ/ลบรถแต่ละคัน
สถิติ กราฟ และรายการทั้งหมดจะกรองตามรถที่เลือกอยู่โดยอัตโนมัติ

นำเข้าข้อมูลจาก Fuelio
-----------------------------------------------------------------
รองรับการนำเข้าไฟล์ backup CSV ที่ export จากแอป Fuelio (Android):
1. ในแอป Fuelio: Settings > Backup > Export CSV (หรือดึงจากไฟล์ที่ sync
   ไว้ใน Google Drive/Dropbox โฟลเดอร์ Fuelio/backup-csv/)
2. เลือกรถที่ต้องการนำเข้าข้อมูลไว้ในแอปนี้ก่อน (ใช้แถบชิปด้านบน หรือสร้าง
   รถใหม่ผ่าน "จัดการรถ")
3. กดปุ่ม "นำเข้า" แล้วเลือกไฟล์ .csv ของ Fuelio ได้เลย ระบบจะอ่านคอลัมน์
   วันที่/เลขไมล์/ปริมาณน้ำมัน/เต็มถัง/ราคา/สถานี ให้อัตโนมัติ

ตัวนำเข้าจะพยายามหาชื่อรถจากไฟล์ Fuelio ให้ด้วย — ถ้าเจอจะถามว่าจะสร้าง
รถใหม่ในแอปตามชื่อนั้นเลยไหม (หรือถ้ามีรถชื่อตรงกันอยู่แล้วก็จะนำเข้าไปที่
รถนั้นให้อัตโนมัติ) ถ้าหาชื่อรถในไฟล์ไม่เจอ จะนำเข้าไปที่รถที่เลือกอยู่ตอนนั้น
แทน — หมายเหตุ: ไฟล์ backup ของ Fuelio ปกติรองรับข้อมูลรถทีละคันต่อไฟล์
ถ้าพี่มีหลายคันใน Fuelio ต้อง export/import แยกไฟล์ทีละคัน

รองรับไฟล์ .fuelio ด้วย (ไฟล์จาก "Backup All" ที่มีรูปภาพติดมา)
-----------------------------------------------------------------
ไฟล์ .fuelio คือไฟล์ zip ที่รวม CSV + โฟลเดอร์รูปภาพไว้ในไฟล์เดียว
กดปุ่ม "นำเข้า" แล้วเลือกไฟล์ .fuelio (หรือ .zip) ได้เลย แอปจะแกะไฟล์ให้เอง
โดยอัตโนมัติ:
1. หาไฟล์ .csv ข้างในที่มีข้อมูลการเติมน้ำมัน
2. หารูปภาพในไฟล์ zip แล้วพยายามจับคู่กับรายการที่มีชื่อไฟล์รูปอ้างอิงไว้
3. รูปที่จับคู่ได้จะถูกแนบเป็น "รูปบิล" ให้อัตโนมัติ (พร้อมแสดงจำนวนรูปที่
   แนบสำเร็จหลังนำเข้าเสร็จ)

หมายเหตุ: โครงสร้างไฟล์ .fuelio ไม่มีเอกสารทางการจาก Fuelio ตัวอ่านนี้เขียน
แบบยืดหยุ่น/เดางานจากตัวอย่างไฟล์ที่พบทั่วไป ถ้าจับคู่รูปไม่ได้บางรายการ
(ชื่อไฟล์รูปในไฟล์ backup ไม่ตรงกับที่คาดไว้) ข้อมูลตัวเลขยังนำเข้าได้ปกติ
แค่ต้องแนบรูปให้รายการนั้นเองภายหลัง — ถ้าอ่านไฟล์ทั้งไฟล์ไม่สำเร็จเลย ลอง
แตกไฟล์ zip เองด้วยแอปจัดการไฟล์ แล้วนำเข้าเฉพาะไฟล์ .csv ข้างในแทน
(ข้อมูลตัวเลขจะเข้าได้ปกติ แค่ไม่มีรูปติดมาอัตโนมัติ)

หมายเหตุ: ไฟล์ backup ของ Fuelio มีโครงสร้างค่อนข้างไม่แน่นอน (ต่างเวอร์ชัน/
ภาษาอาจมีชื่อคอลัมน์ต่างกัน) ตัวนำเข้านี้อ่านแบบยืดหยุ่นโดยหาคอลัมน์จากชื่อ
ที่ใกล้เคียง (Odo, Fuel, Full, Price, City, Notes) และแปลงหน่วยไมล์→กม.
และแกลลอน→ลิตรให้อัตโนมัติหากตรวจพบ แต่แนะนำให้ตรวจสอบรายการหลังนำเข้า
ว่าตัวเลขถูกต้อง โดยเฉพาะไฟล์เก่าหรือที่มาจากเวอร์ชันแปลกๆ ของ Fuelio

แนบรูปบิลและรูปเรือนไมล์ (เหมือน Fuelio)
-----------------------------------------------------------------
ในฟอร์มเพิ่ม/แก้ไขรายการ มีช่องแนบรูป 2 ช่อง: "แนบรูปบิล" และ
"แนบรูปเรือนไมล์" แตะเพื่อถ่ายรูปหรือเลือกจากคลังภาพได้เลย รูปจะถูกย่อขนาด
อัตโนมัติก่อนบันทึก (ไม่เกิน ~1280px) เพื่อประหยัดพื้นที่
ถ้าใช้ปุ่ม "สแกนบิล" (ที่ใช้ AI อ่านข้อมูล) รูปที่ถ่าย/เลือกจะถูกแนบเป็น
รูปบิลให้อัตโนมัติด้วยเลย ไม่ต้องแนบซ้ำ

รูปเก็บแยกไว้ใน IndexedDB ของเบราว์เซอร์ (พื้นที่มากกว่า localStorage มาก)
รายการที่มีรูปแนบจะมีไอคอน 📷 เล็กๆ ต่อท้ายชื่อปั๊มในหน้ารายการ

ข้อจำกัด: ค่าเริ่มต้นการสำรองขึ้น Google Drive อัตโนมัติจะไม่รวมรูปภาพ
(เพื่อความเร็ว) แต่เปิดได้จากหน้าตั้งค่า ดูหัวข้อถัดไป
